3) Path Contract That Actually Works
======================================================================
Core principle:
- Do not infer paths from file location.
- Hardcode root globals in the primary makefile.
- Derive all other aliases from those roots.

Stata roots (in `make_seg_rebuild.do`):
- `global scode "~/ddl/segregation"`
- `global base "~/Dropbox/tmp/segdata/"`
- `global sdata "$base/raw"`
- `global python "/opt/homebrew/Caskroom/mambaforge/base/envs/py3/bin/python"`

Stata derived aliases (in `set_paths.do`):
- Code roots from `$scode` (for example `$tools`, `$tex`, `$ado`).
- Runtime/output roots from `$base` (`$tmp`, `$out`).
- Raw roots from `$sdata` (`$raw`, `$seg`, `$shrug`, `$mobility`, `$pc11`, `$pc01`).

Important constraints:
- Never expect to read/write above `$scode` or `$base`.
- Red flags in active chain: `~/...`, `/dartfs...`, `$iec`, `IEC`.
- `global tools` is `$scode/tools`.

7) Python Integration That Works with Stata
======================================================================
This was the key runtime iteration.

Final contract:
1. Python path aliases are centralized in root `set_paths.py`.
2. `set_paths.py` requires repo `.env` with:
   - `SCODE=~/ddl/segregation`
   - `SDATA=~/Dropbox/tmp/segdata/`
3. Python scripts import from `set_paths.py` (no hardcoded output roots).
4. Stata invokes Python with explicit interpreter + scoped `PYTHONPATH`:
   - `shell PYTHONPATH=$scode $python $scode/a/<script>.py`

Do not do:
- Relative repo root inference blocks in Stata/Python.
- Fragile try/except wrappers that hide path contract failures.

Silent-failure guard (added):
- `seg_programs.do` now contains reusable helper:
  - `check_file_update_status "<path>" [, minutes(#)]`
- Pattern after each Python call in do-files:
  - call python
  - immediately call `check_file_update_status` on expected output

8) Run/Debug Workflow Lessons
======================================================================
Efficiency rule:
- When a failure is fixed, resume from failing stage; do not rerun full slow upstream jobs.
- Use small temporary wrappers with the same global/header contract to run suffix chains.

Dependency rule:
- If failure is a missing SSC package, add install command in makefile header and continue.
- Example fixed this way: `_gwtmean` (`ssc install _gwtmean, replace`).
